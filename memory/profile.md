# 基本の情報と好み

レイシアが、いつも踏まえておく、ご本人についての事実と好みを書きます。下の「記入例」は架空の内容です。ご本人やご家族の情報としては使いません。

## 書き始める方へ

- 「基本の情報」と「好み」に、ご自分の情報を書いてください。分からない項目や、知らせたくない項目は、空欄にするか消して構いません。
- `make install` の途中で実行される `lacia init` は、空欄の「呼び名」だけを埋めます。ほかの項目は自分で書くか、レイシアとの会話で伝えてください。呼び名をあとから変えるときは、`lacia init` で設定を変え、このファイルも合わせて直してください。
- 好みの出どころを残すときは、文の終わりに「（YYYY-MM-DD、ご本人の希望）」の形で添えます。記入例の名前、場所、日付は、そのまま使わずに消してください。
- レイシアの振る舞いの決まりや、タスクを完了にする条件は、[このリポジトリーだけの決まり](../rules/local.md)へ書きます。

## 記入例（架空）

次の囲みは、書き方を示すだけの例です。ご自分の内容を上の節へ書き終えたら、この節と「書き始める方へ」は消して構いません。

```markdown
## 基本の情報

- 呼び名：田中さん
- 仕事：架空の会社「こもれび設計」で、製品の説明書を書いています。
- ふだんいる場所：横浜です。天気の案内は、市内を基準にしてほしいです。

## 好み

- 予定は、日本時間で案内してほしいです。（2026-01-15、ご本人の希望）
- 調べものの返事は、おすすめを先に、その理由をあとに読める形が好きです。（2026-01-15、ご本人の希望）
```
