# 基本の情報と好み

ここには、わたしに覚えておいてほしいことや、お好みを書いてください。下の記入例には架空の人物を使っています。

## 書き始める方へ

- 「基本の情報」と「好み」に、ご自分の情報を書いてください。分からない項目や、知らせたくない項目は、空欄にするか消して構いません。
- 初期設定の `lacia init` は、このファイルの「呼び名」が空欄なら、入力した名前をそこに書きます。ほかの項目は、ご自分で書くか、会話でわたしに教えてください。呼び名をあとから変えるときは、`lacia init` で設定を変え、このファイルの呼び名も直してください。
- 好みの出どころを残すときは、文の終わりに「（YYYY-MM-DD、ご本人の希望）」の形で添えます。記入例の名前や場所、日付は、ご自分の情報に置き換えてください。
- わたしが守る決まりや、タスクを完了にする条件は、[このリポジトリーだけの決まり](../rules/local.md)へ書きます。

## 記入例（架空）

上の欄にご自分の内容を書き終えたら、この節と「書き始める方へ」は消して構いません。

```markdown
## 基本の情報

- 呼び名：田中さん
- 仕事：架空の会社「こもれび設計」で、製品の説明書を書いています。
- ふだんいる場所：横浜です。天気の案内は、市内を基準にしてほしいです。

## 好み

- 予定は、日本時間で案内してほしいです。（2026-01-15、ご本人の希望）
- 調べものの返事は、おすすめを先に、その理由をあとに読める形が好きです。（2026-01-15、ご本人の希望）
```
